# Dateifreigaben

Verzeichnisse im Netzwerk freigeben: NFS für Linux-Clients, Samba für Windows, macOS und
Linux. Freigaben exportieren, die Konfiguration prüfen, Samba-Benutzer verwalten und den
Zugriff testen.

</div>
