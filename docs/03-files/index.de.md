# Dateien

Dateien und Verzeichnisse anlegen, kopieren, verschieben, verlinken und löschen, und
herausfinden, was eine Datei wirklich ist.

</div>

[:material-school-outline:{ .tc-basics-icon } **Grundlagen:** Regeln für sicheres Arbeiten mit Dateien :material-arrow-right:{ .tc-basics-arrow }](basics.md){ .tc-basics }

## Anlegen

<div class="grid cards" markdown>

-   :material-file-plus-outline:{ .lg .middle } **[touch](touch.md)**

    ---

    Legt eine leere Datei an oder aktualisiert ihre Zeitstempel.

-   :material-folder-plus-outline:{ .lg .middle } **[mkdir](mkdir.md)**

    ---

    Legt Verzeichnisse an, auch mit fehlenden übergeordneten Verzeichnissen.

</div>

## Kopieren, verschieben, löschen

<div class="grid cards" markdown>

-   :material-content-copy:{ .lg .middle } **[cp](cp.md)**

    ---

    Kopiert Dateien und Verzeichnisse.

-   :material-file-move-outline:{ .lg .middle } **[mv](mv.md)**

    ---

    Verschiebt oder benennt Dateien und Verzeichnisse um.

-   :material-delete-outline:{ .lg .middle } **[rm](rm.md)**

    ---

    Löscht Dateien und Verzeichnisse endgültig.

-   :material-folder-remove-outline:{ .lg .middle } **[rmdir](rmdir.md)**

    ---

    Löscht leere Verzeichnisse sicher.

-   :material-shredder:{ .lg .middle } **[shred](shred.md)**

    ---

    Überschreibt Dateien sicher, bevor sie gelöscht werden.

</div>

## Links

<div class="grid cards" markdown>

-   :material-link:{ .lg .middle } **[ln](ln.md)**

    ---

    Legt symbolische und harte Links an.

</div>

## Untersuchen und ändern

<div class="grid cards" markdown>

-   :material-file-document-check-outline:{ .lg .middle } **[stat](stat.md)**

    ---

    Zeigt alle Metadaten: Größe, Rechte, Besitzer und Zeitstempel.

-   :material-file-question-outline:{ .lg .middle } **[file](file.md)**

    ---

    Erkennt den Dateityp anhand des Inhalts.

-   :material-content-cut:{ .lg .middle } **[truncate](truncate.md)**

    ---

    Leert, kürzt oder vergrößert eine Datei auf eine exakte Größe.

</div>
