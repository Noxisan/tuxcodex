# Orientation

> Who am I, where am I, and what is going on on this machine?

These are the first commands to run after logging in to a server. They tell you which
user you are working as, which machine you are on, which kernel it runs, how long it has
been up and who else is logged in.

| Command | Description |
|---------|-------------|
| [whoami](whoami.md) | Show the user you are working as |
| [id](id.md) | Show user ID, group ID and group memberships |
| [hostname](hostname.md) | Show or temporarily set the host name |
| [hostnamectl](hostnamectl.md) | Show system information and set the host name permanently |
| [uname](uname.md) | Show kernel release and architecture |
